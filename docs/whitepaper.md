# Cursonic Whitepaper

## Vision

Work that repeats should run itself. Cursonic gives every person a squad of autonomous agents that sit on their own machine, hold their own keys, and report back only when a decision is needed.

## Mission

Make capable, accountable automation local by default, open to inspect, and simple to start with one worker and one errand.

## Principles

- Local-first: transcripts, secrets and events stay on the owner's disk.
- Approval before consequence: risky steps wait in a queue.
- Open source: the hub and the workers can be read, forked and audited.
- Honest numbers: figures appear only once the project owns them.
